# Taurus — Deepnote Notebook Generator

## Purpose

Use when the task is to create or generate a `.ipynb` file compatible with Deepnote, where SQL cells execute BigQuery queries and expose results as named Pandas DataFrames, and Python cells visualize or transform those results.

Produces a `.ipynb` file that can be uploaded to Deepnote and executed immediately, with no manual cell-type conversion required.

## Rules

- Never use plain `requests` or `google-cloud-bigquery` in Python cells as a substitute for a SQL cell — always use the Deepnote SQL cell format.
- Never fabricate the `sql_integration_id` — always extract it from an existing notebook in the user's project or ask the user to provide it.
- All SQL aggregation must happen in the SQL cell itself. Python cells only merge, compute derived columns, and render charts.
- Exclude `sale_fee` funding mode from ML discount calculations — it is a platform fee rebate, not a customer-facing discount.
- Use Plotly (`plotly.graph_objects`, `plotly.express`, `make_subplots`) for all charts. Never use matplotlib.
- Every SQL cell variable must follow the pattern `df_N` (e.g., `df_1`, `df_2`, `df_3`).
- The notebook generator script (`/tmp/gen_nb*.py`) must be a plain Python script that writes the `.ipynb` via `json.dump`. Never use `nbformat` — it may not be installed.
- When **converting** a local `.ipynb`: use the Conversion Workflow (see below). Never re-type SQL manually — always extract it programmatically from the source cell using regex on triple-quoted strings or `.format()`-style SQL variables.
- When converting, drop all cells that only contain `bigquery.Client(...)` setup or `from google.cloud import bigquery` imports — Deepnote manages the BQ connection via the integration, not via explicit client instantiation.
- When converting, always clear all cell outputs (`"outputs": []`) and reset `execution_count` to `null`.

## Deepnote Cell Format Specification

### SQL Cell

A Deepnote SQL cell is a standard `code` cell with special metadata. The Python `source` is boilerplate generated by Deepnote — **the actual SQL lives only in `metadata.deepnote_source`**.

```json
{
  "cell_type": "code",
  "source": [
    "if '_dntk' in globals():\n",
    "  _dntk.dataframe_utils.configure_dataframe_formatter('df_1')\n",
    "else:\n",
    "  _deepnote_current_table_attrs = '{}'\n",
    "\n",
    "df_1 = _dntk.execute_sql(\n",
    "  '<SQL string>',\n",
    "  '<SQL_CONST_ID>',\n",
    "  audit_sql_comment='',\n",
    "  sql_cache_mode='cache_disabled',\n",
    "  return_variable_type='dataframe'\n",
    ")\n",
    "df_1"
  ],
  "outputs": [],
  "execution_count": null,
  "metadata": {
    "deepnote_cell_type": "sql",
    "deepnote_variable_name": "df_1",
    "sql_integration_id": "<UUID>",
    "deepnote_source": "<SQL string>",
    "cell_id": "<uuid4_hex>"
  }
}
```

**Key fields:**

| Field | Value |
|---|---|
| `cell_type` | `"code"` (always — Deepnote renders via metadata) |
| `metadata.deepnote_cell_type` | `"sql"` |
| `metadata.deepnote_variable_name` | `"df_N"` — the Python variable exposed after execution |
| `metadata.sql_integration_id` | UUID of the BigQuery integration in the Deepnote project |
| `metadata.deepnote_source` | The raw SQL string (same string passed to `_dntk.execute_sql`) |
| `source[5]` | `df_N = _dntk.execute_sql(...)` where the first arg equals `deepnote_source` |

### SQL Constant Naming

The `SQL_CONST` string passed as the second argument to `_dntk.execute_sql` is derived from the integration UUID with dashes replaced by underscores and uppercased:

```
UUID:   5088268a-9640-458a-83d1-46b07b955fae
CONST:  SQL_5088268A_9640_458A_83D1_46B07B955FAE
```

### Python Cell

```json
{
  "cell_type": "code",
  "source": ["<python source>"],
  "outputs": [],
  "execution_count": null,
  "metadata": {
    "deepnote_cell_type": "code",
    "cell_id": "<uuid4_hex>"
  }
}
```

### Markdown Cell

```json
{
  "cell_type": "markdown",
  "source": ["<markdown text>"],
  "metadata": {
    "deepnote_cell_type": "markdown",

```

## Workflow

### Phase 1 — Gather context

1. Confirm the BigQuery project and dataset names with the user.
2. Confirm or extract the `sql_integration_id` UUID:
   - Preferred: grep an existing `.ipynb` in the project for `"sql_integration_id"`.
   - Fallback: ask the user to open Deepnote → project settings → integrations → copy the UUID.
3. List the source tables and their key columns (run `bq show` or read existing dbt models).
4. Identify what analysis sections are needed (time-series, funnels, top-N, etc.).

### Phase 2 — Design SQL queries

1. Write one SQL query per analysis section.
2. All GROUP BY, DATE_TRUNC, COUNTIF, and JOIN logic must be in SQL — not in Python.
3. Assign sequential variable names: `df_1`, `df_2`, `df_3`, ...
4. Filter incomplete periods: `WHERE date_col < DATE_TRUNC(CURRENT_DATE(), MONTH)`.
5. Use `QUALIFY ROW_NUMBER() OVER (PARTITION BY id ORDER BY ingestion_date DESC) = 1` for deduplication.

### Phase 3 — Design Python cells

1. One `setup` Python cell: imports (`pandas`, `numpy`, `plotly`), display options, color constants.
2. One `prep` Python cell: merge DataFrames, compute derived columns (`roas`, `pct`, etc.), print a summary.
3. One Python cell per chart. Each chart cell:
   - Reads from a `df_N` variable (already aggregated).
   - Produces a single `fig.show()` call.
   - Uses `make_subplots` for multi-panel layouts.

### Phase 4 — Generate the notebook

Write a generator script at `/tmp/gen_nb_<topic>.py`:

```python
import json, uuid

INTEGRATION_ID = "<UUID>"
SQL_CONST = "SQL_<UPPER_UUID_NO_DASHES>"

def sql_cell(var, sql):
    src = [
        "if '_dntk' in globals():\n",
        "  _dntk.dataframe_utils.configure_dataframe_formatter('{}')\n".format(var),
        "else:\n",
        "  _deepnote_current_table_attrs = '{}'\n",
        "\n",
        var + " = _dntk.execute_sql(\n",
        "  " + repr(sql) + ",\n",
        "  '" + SQL_CONST + "',\n",
        "  audit_sql_comment='',\n",
        "  sql_cache_mode='cache_disabled',\n",
        "  return_variable_type='dataframe'\n",
        ")\n",
        var,
    ]
    return {
        "cell_type": "code", "source": src, "outputs": [], "execution_count": None,
        "metadata": {
            "deepnote_cell_type": "sql", "deepnote_variable_name": var,
            "sql_integration_id": INTEGRATION_ID, "deepnote_source": sql,
            "cell_id": uuid.uuid4().hex,
        },
    }

def py_cell(src):
    return {
        "cell_type": "code", "source": [src], "outputs": [], "execution_count": None,
        "metadata": {"deepnote_cell_type": "code", "cell_id": uuid.uuid4().hex},
    }

def md_cell(src):
    return {
        "cell_type": "markdown", "source": [src],
        "metadata": {"deepnote_cell_type": "markdown", "cell_id": uuid.uuid4().hex},
    }

# ... define SQL_1, SQL_2, PY_SETUP, PY_CHART ... then:

nb = {
    "nbformat": 4, "nbformat_minor": 5,
    "metadata": {
        "kernelspec": {"display_name": "Python 3", "language": "python", "name": "python3"},
        "language_info": {"name": "python", "version": "3.11.8"},
        "deepnote_notebook_id": uuid.uuid4().hex,
        "deepnote_execution_queue": [],
    },
    "cells": [ ... ],
}

with open("<output_path>.ipynb", "w") as f:
    json.dump(nb, f, indent=1, ensure_ascii=False)
```

Run with: `python3 /tmp/gen_nb_<topic>.py`

### Phase 5 — Validate

1. Confirm exit code 0 and cell count matches expected.
2. Open the `.ipynb` in VS Code and verify SQL cells show the SQL source in the `deepnote_source` metadata field.
3. Optionally upload to Deepnote and execute to confirm SQL cells run correctly.

## Conversion Workflow: Local `.ipynb` → Deepnote

Use this workflow when the user has an existing local notebook (standard Jupyter / VS Code format) and wants to upload it to Deepnote with working SQL cells.

### Phase 0.1 — Inspect source notebook

1. Read the source `.ipynb` JSON and list all cells with their type and first 3 lines of source.
2. Identify the **BQ query cells**: cells that call `client.query(...)`, `.to_dataframe()`, or reference `bigquery`.
3. Identify **setup cells** that only do `from google.cloud import bigquery` / `bigquery.Client(...)` → these will be **dropped**.
4. Confirm or extract the `sql_integration_id` UUID (grep project `.ipynb` files for `"sql_integration_id"`).

### Phase 0.2 — Write a converter script

Create `/tmp/convert_to_deepnote_<topic>.py` using the template below. Run it and verify exit code 0.

```python
#!/usr/bin/env python3
"""
convert_to_deepnote.py  —  local .ipynb → Deepnote-compatible .ipynb
Usage: python3 convert_to_deepnote_<topic>.py
"""
import json, re, sys, uuid

INTEGRATION_ID = "<UUID>"  # replace with actual UUID
SQL_CONST      = "SQL_" + INTEGRATION_ID.upper().replace("-", "_")
INPUT_PATH     = "<source.ipynb>"
OUTPUT_PATH    = "<output_deepnote.ipynb>"

# ── Heuristics ────────────────────────────────────────────────────────────────
BQ_MARKERS = [r'client\.query\s*\(', r'\.to_dataframe\(\)', r'bigquery\.Client']
SETUP_MARKERS = ["from google.cloud import bigquery", "bigquery.Client("]

def is_bq_cell(src: str) -> bool:
    return any(re.search(p, src) for p in BQ_MARKERS)

def is_setup_only_cell(src: str) -> bool:
    lines = [l.strip() for l in src.splitlines() if l.strip() and not l.strip().startswith('#')]
    return all(any(m in l for m in SETUP_MARKERS) for l in lines)

def extract_sql(src: str) -> str | None:
    # 1) triple-quoted variable: sql = """..."""
    m = re.search(r'(?:sql|query|SQL)\s*=\s*[rf]?"""(.*?)"""', src, re.DOTALL)
    if m:
        return m.group(1).strip()
    # 2) .format() variable: sql = """...{param}...""" (keep placeholders as-is)
    # 3) inline: client.query("""...""", ...)
    m = re.search(r'client\.query\s*\([rf]?"""(.*?)"""', src, re.DOTALL)
    if m:
        return m.group(1).strip()
    return None

# ── Cell builders ─────────────────────────────────────────────────────────────
_var_n = 0
def next_var() -> str:
    global _var_n; _var_n += 1; return f"df_{_var_n}"

def sql_cell(var: str, sql: str) -> dict:
    src = [
        "if '_dntk' in globals():\n",
        f"  _dntk.dataframe_utils.configure_dataframe_formatter('{var}')\n",
        "else:\n",
        "  _deepnote_current_table_attrs = '{}'\n",
        "\n",
        f"{var} = _dntk.execute_sql(\n",
        f"  {repr(sql)},\n",
        f"  '{SQL_CONST}',\n",
        "  audit_sql_comment='',\n",
        "  sql_cache_mode='cache_disabled',\n",
        "  return_variable_type='dataframe'\n",
        ")\n",
        var,
    ]
    return {
        "cell_type": "code", "source": src, "outputs": [], "execution_count": None,
        "metadata": {
            "deepnote_cell_type": "sql", "deepnote_variable_name": var,
            "sql_integration_id": INTEGRATION_ID, "deepnote_source": sql,
            "cell_id": uuid.uuid4().hex,
        },
    }

def py_cell(src: str) -> dict:
    return {
        "cell_type": "code", "source": [src], "outputs": [], "execution_count": None,
        "metadata": {"deepnote_cell_type": "code", "cell_id": uuid.uuid4().hex},
    }

def md_cell(src: str) -> dict:
    return {
        "cell_type": "markdown", "source": [src],
        "metadata": {"deepnote_cell_type": "markdown", "cell_id": uuid.uuid4().hex},
    }

# ── Main ──────────────────────────────────────────────────────────────────────
def convert() -> None:
    with open(INPUT_PATH) as f:
        nb = json.load(f)

    new_cells, skipped, converted_sql = [], 0, 0
    for cell in nb["cells"]:
        source = "".join(cell.get("source", []))

        if cell["cell_type"] == "markdown":
            new_cells.append(md_cell(source))

        elif cell["cell_type"] == "code":
            if is_setup_only_cell(source):
                skipped += 1
                continue  # drop BQ client setup — Deepnote handles this
            if is_bq_cell(source):
                sql = extract_sql(source)
                if sql:
                    new_cells.append(sql_cell(next_var(), sql))
                    converted_sql += 1
                else:
                    # SQL could not be extracted automatically — keep as Python, add TODO comment
                    new_cells.append(py_cell("# TODO: convert manually to SQL cell\n" + source))
            else:
                new_cells.append(py_cell(source))

    out_nb = {
        "nbformat": 4, "nbformat_minor": 5,
        "metadata": {
            "kernelspec": {"display_name": "Python 3", "language": "python", "name": "python3"},
            "language_info": {"name": "python", "version": "3.11.8"},
            "deepnote_notebook_id": uuid.uuid4().hex,
            "deepnote_execution_queue": [],
        },
        "cells": new_cells,
    }

    with open(OUTPUT_PATH, "w") as f:
        json.dump(out_nb, f, indent=1, ensure_ascii=False)

    print(f"✓  {len(new_cells)} cells written to {OUTPUT_PATH}")
    print(f"   {converted_sql} SQL cells converted, {skipped} setup cells dropped")
    todos = sum(1 for c in new_cells if c["cell_type"]=="code" and "TODO: convert manually" in "".join(c["source"]))
    if todos:
        print(f"   ⚠️  {todos} cells need manual SQL extraction (search for '# TODO')")

if __name__ == "__main__":
    convert()
```

### Phase 0.3 — Post-conversion checklist

1. Open the output `.ipynb` in VS Code — verify each converted cell has `"deepnote_cell_type": "sql"` in its metadata.
2. Search for `# TODO: convert manually` — fix any cells where SQL extraction failed.
3. Confirm `sql_integration_id` is set on every SQL cell (not `<UUID>`).
4. Upload to Deepnote and run all cells to validate end-to-end.

### SQL extraction edge cases

| Pattern in source cell | Extraction strategy |
|---|---|
| `sql = """SELECT ..."""` | regex `sql\s*=\s*[rf]?"""(.*?)"""` |
| `client.query("""SELECT ...""")` | regex `client\.query\s*\([rf]?"""(.*?)"""` |
| `sql = """...{param}...""".format(...)` | extract SQL verbatim (keep `{param}` — Deepnote will fail at runtime, but it's a starting point) |
| Multi-cell SQL (variable defined in cell A, used in cell B) | Join cells manually or restructure into one SQL cell |
| `pd.read_gbq(query)` | Extract from `query` variable using same regex |

## Plotly Patterns

### Color constants (Mercado Livre palette)
```python
ML_YELLOW = "#FFE600"
ML_BLUE   = "#3483FA"
GREEN     = "#00A650"
ORANGE    = "#FF6B35"
RED       = "#e74c3c"
PURPLE    = "#9B59B6"
```

### Conditional bar colors (e.g., ROAS)
```python
colors = [GREEN if v >= 5 else (ML_YELLOW if v >= 1 else RED) for v in series]
```

### Dual-axis layout
```python
fig = make_subplots(specs=[[{"secondary_y": True}]])
fig.add_trace(..., secondary_y=False)   # bars on left axis
fig.add_trace(..., secondary_y=True)    # lines on right axis
```

### Base layout dict (reuse across charts)
```python
BASE = dict(plot_bgcolor="white", paper_bgcolor="white", font=dict(family="Arial", size=11))
fig.update_layout(**BASE, height=460, ...)
```

## Guardrails

- Do not use `nbformat` library — use `json.dump` directly.
- Do not add `sale_fee` rows to discount aggregations — always filter `WHERE funding_mode != 'sale_fee'`.
- Do not put aggregation logic in Python prep cells — keep SQL cells doing the heavy lifting.
- Do not hardcode dates — use `DATE_TRUNC(CURRENT_DATE(), MONTH)` to exclude the current incomplete month.
- Do not store credentials or project secrets in the notebook source — rely on ADC (Application Default Credentials) via the Deepnote integration.
- Do not generate cell IDs as static strings — always use `uuid.uuid4().hex` per cell to avoid Deepnote ID conflicts.
- Do not use `matplotlib` — Deepnote renders Plotly natively with interactivity.
