# Contexto do GitHub — índice para o Codex

Este diretório é um snapshot dos arquivos de contexto do GitHub do projeto
`LA_Coding_Projects`, exportado em 2026-07-27.

## Regra de uso

- Consulte `copilot-instructions.md` quando a tarefa envolver arquitetura,
  fontes BigQuery, regras de domínio ou convenções de output.
- Consulte prompts específicos somente quando a tarefa corresponder ao tema do
  prompt.
- Trate o conteúdo como contexto histórico e valide regras, caminhos, schemas e
  premissas contra o estado atual do projeto.
- Em caso de conflito, prevalecem, nesta ordem: pedido atual do usuário,
  `AGENTS.md`, código/dados atuais e, por último, este snapshot.
- Não exponha credenciais ou conteúdo sensível eventualmente referenciado.

## Escopo da exportação

Foram exportados somente arquivos Markdown de instruções e prompts. Configurações
locais, credenciais e outros artefatos não fazem parte deste snapshot.

## Sincronização

Este snapshot não é sincronizado automaticamente. Quando `.github/` mudar,
copie novamente os arquivos catalogados e valide a paridade entre origem e
destino.
