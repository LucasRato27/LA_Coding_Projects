# Task Completion Checklist

Ao finalizar uma tarefa neste projeto:

1. **Verificar outputs**: Se a tarefa gerou outputs (Excel, CSV, imagens), garantir que estão salvos em `3_Outputs/`
2. **Versionamento do notebook**: Atualizar nome do arquivo com data se houver mudanças significativas (ex: `_v20260415`)
3. **Git**: Fazer commit e push das alterações
4. **Sem linting/formatting automático**: Projeto é baseado em notebooks, não há ferramentas de lint/format configuradas
5. **Sem testes automatizados**: Projeto analítico, validações são feitas visualmente nos outputs
6. **Documentação**: Adicionar markdown cells descritivas nas seções novas do notebook
